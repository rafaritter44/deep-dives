# Get Started POC

Source:
- https://www.haskell.org/get-started/
- https://www.haskell.org/ghcup/steps/

Run:
```
ghc hello.hs
./hello
```

Or:
```
ghci hello.hs
main
```

Or simply:
```
runghc hello.hs
```

Use the `-Wall` flag to emit warnings about the code. For example:
```
runghc -Wall hello.hs
```
